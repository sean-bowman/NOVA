Download the `-win64.zip` file below, unzip it and run `NOVA\NOVA.exe`. It needs no Python or other install: Windows 10 or 11, 64-bit, with the Microsoft Edge WebView2 Runtime, which Windows 11 includes.

This release is not code-signed. The first time, Windows may show "Windows protected your PC": click **More info**, then **Run anyway**.

`README.txt` in the folder says where NOVA keeps its runs, exports and log.
