# NOVA Validation Status

The validation status of each model behind NOVA's reported results, written from [validationStatus.json](validationStatus.json) by `python -m novaGui.validationStatus --write`. Each status stands on the records linked in its row, which carry the quoted passage word for word; `tests/testValidationStatus.py` fails when one no longer does. The GUI's result table shows the same statuses on its headline numbers and sections, each the weakest status among the models behind it.

## Statuses

| Status | Meaning |
| --- | --- |
| Validated | Reproduces a closed form, reference data, a published benchmark or hardware data, with the error quantified and inside its acceptance criterion. |
| Calibrated | Fitted to a reference, so the agreement with it is by construction; trusted only as far as the reference reaches. |
| Compared | Compared with measured data, but the error is outside the acceptance criterion or the comparison spans a band wider than its tolerance. |
| Cross-checked | Agrees with an independent tool that is itself unvalidated: consistent, not shown correct. |
| Unvalidated | No reference applies or the one available fails; the record names the sanity checks run in its place. |
| By construction | Geometry or accounting on the inputs rather than a physical model; tests hold its identities. |

| Throat sizing and discharge coefficient | Validated | Kliegel and Levine's transonic discharge coefficient; CEA's equilibrium characteristic velocity | The throat is sized with Kliegel and Levine's coefficient, which an inviscid finite-volume solution reproduces to 0.01 percent, and agrees with CEA's characteristic velocity to 0.02 percent. | [NozzleContourValidation.md](NozzleContourValidation.md), [README.md](../validation/openFoam/README.md) |
